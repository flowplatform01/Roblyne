Eliminate URL-Based Image Inputs
This is mandatory.
Any feature that represents uploaded media must use proper file upload components.
Never require users to paste image URLs.
Replace URL image inputs with professional upload experiences.
Examples include but are not limited to:
Organization logos
Profile photos
Candidate photos
Campaign covers
Event banners
Event galleries
Voting banners
Images throughout the application
Provide intuitive upload interfaces.
Support preview.
Support replacement.
Support removal.
Support drag-and-drop where appropriate.
Support mobile image selection.
The experience must feel modern and professional.
Only retain URL fields where URLs are genuinely part of the business data itself, such as:
Meeting links
External websites
Social links
Reference URLs
Never use URLs as substitutes for media uploads.
